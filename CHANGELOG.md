# Changelog

All notable changes to `@digital-india-project/dip-analytics` are documented in this file.

## [0.1.0] - 2026-11-27

### Added
- **Event Contracts, Upcasters & Schemas:** Added 13 versioned v`1.0.0` event contracts (`src/contracts/events.ts`), `EventUpcasterRegistry` for multi-step schema migrations with cycle detection (`src/contracts/upcasters.ts`), schema compatibility checker, Draft 2020-12 JSON Schemas (`src/schemas/event-schemas.ts`), and W3C `traceparent` / OpenTelemetry attribute helpers (`src/telemetry/context.ts`).
- **Privacy & Tenant Isolation:** Added recursive PII/document/circular-reference/prototype-pollution guard (`src/privacy/pii-guard.ts`), trusted `TenantAuthorizationContext` and branded `AuthorizedTenantQuery` enforcement (`src/privacy/tenant-boundary.ts`), and strict runtime event/batch validation (`src/validation/event-validator.ts`).
- **Reliability, Performance & Utilities:** Added strict calendar-aware ISO-8601 parsing, date-range & bucket-count (`10,000`) guardrails, IANA timezone bucketing (`src/utils/time.ts`), `BigInt`-backed integer minor-unit financial arithmetic (`src/utils/money.ts`), `O(N)` Schwartzian deterministic event sorting, deduplication, SHA-256 event fingerprinting, and high-cardinality `__other__` rollups with merged duration stats (`src/reliability/index.ts`, `src/aggregations/math.ts`).
- **Aggregations & Universal Scalable Engine:** Implemented deterministic aggregation modules under `src/aggregations/` covering funnel, universal custom-stage funnel, status distribution, open-application backlog & aging histograms, service performance, service unit economics & net contribution margin, processing/SLA, revenue/refunds, payment metrics, payment reconciliation, partner performance, operator & queue workload, opaque account activity, account cohort retention curves, geographic/regional analytics, API metrics, historical time-series, period-over-period comparison, rolling-baseline anomaly detection, and checkpointed single-pass `StreamingAnalyticsProcessor` (`exportCheckpoint`/`fromCheckpoint`) with associative `mergeTenantRollups`.
- **Storage, Reporting, Ecosystem Bridges & Dashboards:** Added database-agnostic storage/ingestion/idempotency/retention/snapshot interfaces with `iterateByTenant` streaming cursors and test-only `InMemoryAnalyticsStore` (`src/storage/`), aggregate-only CSV/JSON/NDJSON exporters with OWASP formula neutralization and K-anonymity small-cell suppression (`src/reporting/`), framework-agnostic ecosystem bridges (`src/ecosystem/bridges.ts`) for `DIPINDIA`, `dip-api`, and `dip-automation`, and 7 enriched dashboard response contracts and builders (`src/dashboards/`).
- **Documentation, Tests, Benchmark & CI:** Added 10 synthetic `node:test` suites (43 passing tests, including 10,000-event streaming/merge verification), 100,000-event throughput benchmark (`npm run benchmark`), full `docs/*` suite, `integration/manifest.json`, `SECURITY.md`, and `.github/workflows/ci.yml`.
